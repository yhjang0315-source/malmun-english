# 말문 English

자격증 시험 대비부터 회화까지 다루는 영어 학습 앱입니다. Claude 아티팩트로 게시해 사용합니다.

## 들어 있는 것

- `malmun-english.html` — 앱 본체 (아티팩트 페이지 한 장)
- `ill/00.webp` ~ `ill/89.webp` — 단어·표현 90개의 웹툰풍 일러스트 (앱이 `ill/NN.webp` 경로로 불러옴)
- `malmun-icon.svg`, `malmun-icon.png` — 앱 아이콘
- `illust-trial/` — 그림 스타일을 고를 때 만든 시안

## 기능

- 시험 문제 272문항 (TOEIC 등), 단원별 진행 표시
- 단어장 3종 (TOEIC / 회화 / 학술), 각 30개, 일러스트 켜기·끄기
- 회화 연습, 영작 첨삭, 오늘의 표현
- 공부 계획 세우기
- 색 테마 13종, 아트 테마 10종

## 참고

- 회화·첨삭·읽어 주기·기록 저장은 Claude 아티팩트 기능을 쓰므로, HTML 파일만 브라우저로 열면 그 부분은 동작하지 않습니다.
- 일러스트는 이미지 생성 AI(GPT 이미지 모델, 일부 Canva)로 만들었습니다.
